# Memory Layout Calculation for Hardware Accelerator

## 1. Introduction

This document provides a detailed breakdown of the memory layout for the quantized transformer model, specifically for the `mem.txt` file loaded by the hardware accelerator. It explains how different data types (inputs, weights, biases) are packed into 32-bit words and calculates the total memory footprint based on the specified model architecture.

The final calculation corroborates the observed file size of **47,920 lines**.

## 2. Model & Architecture Parameters

The calculation is based on the following model dimensions. The number of attention heads (`H`) was determined to be **1** based on the total memory size.

| Parameter          | Variable | Value | Description                  |
| ------------------ | :------: | :---: | ---------------------------- |
| Sequence Length    |   `S`    |  64   | Number of input tokens       |
| Embedding Size     |   `E`    |  128  | Dimension of token vectors   |
| Projection Space   |   `P`    |  192  | Output dimension per head    |
| Feed-Forward Size  |   `F`    |  256  | Inner dimension of FFN layer |
| Number of Heads    |   `H`    |   1   | Number of attention heads    |

## 3. Data Packing Schemes

To optimize memory usage, values are packed into 32-bit words based on their bit-width. Each line in `mem.txt` represents one 32-bit word.

### 8-bit Value Packing (Inputs & Weights)

Inputs (`Q`, `K`, `FF`) and weights (`Wq`, `Wk`, etc.) are 8-bit integers.

-   **Packing Ratio**: 4 values per 1 word.
-   **Calculation**: $4 \times 8\text{-bit} = 32\text{-bit}$

### 24-bit Value Packing (Biases)

All bias vectors (`Bq`, `Bk`, etc.) are 24-bit integers.

-   **Packing Ratio**: 4 values per 3 words.
-   **Calculation**: $4 \times 24\text{-bit} = 96\text{-bit}$, which fits perfectly into $3 \times 32\text{-bit} = 96\text{-bit}$.

## 4. `mem.txt` Content Calculation

The `mem.txt` file is generated by concatenating the model's inputs, attention parameters, and FFN parameters.

### Section 1: Input Tensors

These tensors are packed using the 8-bit scheme.

| Tensor | Shape `(S, E)` | Total Values | Word Count (Lines) |
| :----: | :------------: | :----------: | :----------------: |
|  `Q`   |   `(64, 128)`  |    8,192     |       2,048        |
|  `K`   |   `(64, 128)`  |    8,192     |       2,048        |
|  `FF`  |   `(64, 128)`  |    8,192     |       2,048        |
|        |                | **Subtotal** |    **6,144** |

### Section 2: Attention Layer Parameters (H=1)

-   **Weights (`Wq`, `Wk`, `Wv`, `Wo`)**
    -   Type: 8-bit (packed 4-to-1)
    -   Shape: Four matrices of size `(128, 192)`
    -   Total Values: $4 \times (128 \times 192) = 98,304$
    -   Word Count: $98,304 \div 4 = \textbf{24,576}$

-   **Biases (`Bq`, `Bk`, `Bv`, `Bo`)**
    -   Type: 24-bit (packed 4-to-3)
    -   `Bq, Bk, Bv`: Three vectors of size `P=192`
        -   Word Count: $3 \times (192 \div 4) \times 3 = \textbf{432}$
    -   `Bo`: One vector of size `E=128`
        -   Word Count: $1 \times (128 \div 4) \times 3 = \textbf{96}$

| Component          | Word Count (Lines) |
| ------------------ | :----------------: |
| Attention Weights  |       24,576       |
| Attention Biases   |     432 + 96       |
| **Subtotal** |    **25,104** |

### Section 3: Feed-Forward (FFN) Layer Parameters

-   **Weights (`Wff`, `Wff2`)**
    -   Type: 8-bit (packed 4-to-1)
    -   Shape: `(128, 256)` and `(256, 128)`
    -   Total Values: $2 \times (128 \times 256) = 65,536$
    -   Word Count: $65,536 \div 4 = \textbf{16,384}$

-   **Biases (`Bff`, `Bff2`)**
    -   Type: 24-bit (packed 4-to-3)
    -   `Bff`: One vector of size `F=256`
        -   Word Count: $1 \times (256 \div 4) \times 3 = \textbf{192}$
    -   `Bff2`: One vector of size `E=128`
        -   Word Count: $1 \times (128 \div 4) \times 3 = \textbf{96}$

| Component      | Word Count (Lines) |
| -------------- | :----------------: |
| FFN Weights    |       16,384       |
| FFN Biases     |      192 + 96      |
| **Subtotal** |    **16,672** |

## 5. Final Verification

Summing the word counts from all sections gives the total number of lines in `mem.txt`.

| Section               | Word Count (Lines) |
| --------------------- | :----------------: |
| Input Tensors         |       6,144        |
| Attention Layer       |       25,104       |
| Feed-Forward Layer    |       16,672       |
| **Grand Total** |    **47,920** |

This calculation perfectly matches the observed file size, confirming the memory layout and model architecture.
